Dataset and code

Dataset: Multi-class Weather Dataset (Kaggle), 1500 images in 5 classes: cloudy, foggy, rainy, shine, sunrise. Plus 900 synthetic color images (solid colors, gradients, blocks, noise, blur) in a sixth class, other, meaning not a weather photo. Total 2400 images, split 70 / 15 / 15 into train, validation and test.

How colors are detected: uploaded photos use the HSV formula directly (exact). The live camera uses the CNN, which was trained to predict the same values.

Labels: weather comes from the folder name. Color percentages (11 colors), brightness and color temperature are generated automatically from each image with an HSV script.

Model: MobileNetV2 transfer learning with one shared layer and 4 outputs: color percentages, brightness, color temperature and weather. Trained in two phases (frozen base, then fine-tuning) and converted to TensorFlow.js to run in your browser.

Test result (360 images)Score
Weather accuracy98.1% (6 classes)
Color percentage error7.3 points on average
Dominant color accuracy60%
Brightness accuracy77.5%
Color temperature accuracy71.7%

Limits: 135 of the 360 test images are synthetic and easy, so weather accuracy on real photos only is lower than 98%. Blue and gray have the largest color error because sky and clouds overlap. Brightness and temperature labels come from thresholds, so images near a threshold are often confused.
